# Portfolio de automatizaciones

Web estática (HTML + CSS + JS), lista para GitHub Pages.

## Archivos
- `index.html`: la página completa.
- `styles.css`: estilos.
- `config.js`: **acá cambiás WhatsApp, email y el mensaje prearmado**.
- `foto.jpg`: tu foto.
- `planilla-muestra-stock-y-caja.xlsx`: planilla descargable (datos inventados).

## Publicar en GitHub Pages
1. Creá un repositorio público (ej.: `portfolio-automatizaciones`) y subí estos archivos.
2. En el repo: Settings → Pages → Source: "Deploy from a branch" → rama `main`, carpeta `/ (root)`.
3. En 1-2 minutos queda en `https://TUUSUARIO.github.io/portfolio-automatizaciones/`.

## Antes de publicar
- `linkedin-acerca-de-anterior.txt` es un backup personal con datos que no conviene mostrar. Está en `.gitignore`, pero lo más seguro es moverlo fuera de esta carpeta.
- Revisá los textos de ejemplo: son demostrativos, con datos inventados. Cuando tengas clientes reales (con su permiso), reemplazalos por casos reales.
